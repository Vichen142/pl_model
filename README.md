# ⚽ Premier League Season Predictor & Simulation Radar

An end-to-end machine learning web application that forecasts English Premier League fixtures and simulates complete league standings using dynamic team ratings and Monte Carlo methods.

---

## 🚀 Live Demo
- **Web App:** [Launch Live Application](https://pl-model-gold-apple.reflex.run/)

---

## 📌 Key Features
- **Match Outcome Forecasting:** Predicts probabilities for Home Win, Draw, and Away Win using an ensemble Random Forest classifier.
- **Dynamic Elo Rating System:** Continuously adjusts team strength based on fixture difficulty, goal differentials, and recent form.
- **Monte Carlo Season Simulation:** Simulates the remainder of the league campaign thousands of times to determine title, top-four, and relegation probabilities.
- **Interactive UI:** Built with Reflex for responsive, stateful analytics.

---

## 🛠 Tech Stack
- **Language:** Python
- **Modeling & Analytics:** Scikit-learn, Pandas, NumPy
- **Frontend / Full-Stack Framework:** Reflex
- **Simulation:** Stochastic Monte Carlo modeling
